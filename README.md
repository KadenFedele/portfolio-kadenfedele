# Kaden Fedele — Personal Portfolio

A portfolio site built from scratch in HTML and CSS for WRIT 40363.
It introduces who I am, what I am learning, and the work I have made.

**Live site:** https://kadenfedele.github.io/portfolio-kadenfedele

## Built with

- Semantic HTML5
- CSS with design tokens, Flexbox, and Grid
- Git and GitHub Pages

## Notes

Layout has evolved lab by lab — starting with Flexbox and moving to CSS
Grid for the skills and projects sections, with a documented 768px
breakpoint. A couple of TODOs are still marked directly in the HTML
(the header photo and the placement of `screensaver.png`) and will be
resolved in a later lab.
